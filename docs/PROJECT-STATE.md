- **Current implementation:** `GEMINI_MODEL` is read from `local.properties` with a `gemini-flash-latest` default. Gemini model discovery filters Flash models advertising `generateContent`, prioritizes discovered candidates over stale cache/configuration, and tries at most three candidates. The list endpoint does not expose function-calling support, so a model-specific unsupported-tools HTTP 400 advances to another discovered candidate. HTTP 404 advances; 503 retries with bounded backoff then advances; transient 429 honors `Retry-After` up to five seconds. A permanent quota-exhaustion 429 now falls back immediately after discovery rather than repeating requests against candidates. Every attempt records model and HTTP status in Decision Trace; History displays model and timestamp; Home labels the responding model or degraded reason. A v2→v3 Room migration adds the model field non-destructively. Meeting fallback recognizes visits, asks AM/PM when an approximate hour is ambiguous, and preserves explicit title, venue, and requested weekday/date through follow-ups into calendar creation. WhatsApp uses a direct `wa.me` deep link with a prefilled draft when the contact has an international phone number; it does not guess a country code for local-only numbers.
